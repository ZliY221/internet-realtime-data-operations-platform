# 系统架构

## 数据链路

```text
业务服务 / 指标模拟器
        |
        v
POST /api/v1/metrics
        |
        +--> 指标校验与持久化 --> traffic_metrics
        |
        +--> 告警规则计算 ------> alerts
        |
        +--> WebSocket 广播 ----> Vue 运营看板
```

后端按分钟粒度保存服务指标。写入完成后，告警策略依据错误率和 P95 响应时间进行判断；满足规则时生成告警，并把指标与告警事件推送给在线页面。看板的首次加载使用 REST 查询，后续变化由 WebSocket 增量更新。

## 模块边界

- `metric`：指标接入、持久化与最近窗口查询。
- `alert`：告警规则、状态机和处置接口。
- `dashboard`：运营摘要聚合。
- `realtime`：WebSocket 连接与事件广播。
- `frontend`：指标展示、趋势分析和告警处置。

## 数据一致性

指标和由该指标触发的告警在同一事务中写入。WebSocket 广播在事务提交后执行，页面收到事件时可立即通过 REST 查询到对应数据。
